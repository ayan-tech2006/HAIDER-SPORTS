HAIDERSPORTS ADMIN GUIDE

Dukaan aur Website chalane ka mukammal tareeqa (Roman Urdu)

1 Admin Panel Mein Login Kaise Karein?

Browser mein /admin/ link kholein. Apna Admin Email aur Password enter karein aur Login button dabayein. Agar password bhool jayen toh Forgot Password par click karein.

2 Nayi Category / Collection Banana

Sidebar se Collections par jayein aur Add Collection dabayein. Naam likhein aur Parent Category chunein. Yad rahe ke products sirf aakhri subcategory (leaf category) ke andar add ho sakte hain.

3 Naya Product Add Karna & Photos Upload

Sidebar se Products par jayein aur Add Product dabayein. Naam, keemat aur stock enter karein. Media section mein saaf square (1:1) photos upload karein. Bats ke liye + Add Bat Weights dabayein aur leaf category select karke Save Product karein.

4 Customer Orders Ko Handle Karna

Jab naya order aayega, ghanti bajegi aur dashboard par alert aayega. Orders page par jakar Details kholein. Ek click par WhatsApp button se customer ko confirmation bhejein. Jab courier ko parcel dein toh status Shipped karke tracking number darj karein. A4 packing slip ke liye Print Invoice dabayein.

5 Discount Coupons Banana

Sidebar se Coupons par jayein. Create Coupon dabayein, code generate karein (e.g. RASHY10), percentage ya fixed discount chunein aur save karein.

6 Home Page Banners & Offers Badalna

Sidebar se Home Content par jayein. Top slider ke banners badlein, Flash deal ka countdown end-date set karein aur catalog ke behtareen products ko Featured star lagayein.

7 Delivery Charges & Helpline Badalna

Sidebar se Settings par jayein. Apna helpline phone, WhatsApp number aur nationwide shipping rate badal kar Save Settings dabayein.
